Football Hub - Website Project Site Plan

Site Name

Football Hub

Site Purpose

Football Hub will provide football fans with information about a football club, including its history, players, fixtures, results, and achievements.

Target Audience

The website is designed for football fans who want a simple and easy-to-use source of information about the club.

Site Content

The website will contain information about the club's history, players, fixtures, results, achievements, and latest updates.

Website Pages

  • Home-Introduction to the football club and hughlights.
  • Team-Information about players and the squad.
  • Fixtures & Results-Upcoming fixtures and previous match results.

Color Scheme

The website will use dark blue as the primary color, white as the background color, and a light blue accent color for highlights and interactive elements.

Dark Blue - #0b1f3a
White - #ffffff
Light Blue - #4da6ff

Typography

Heading Font: Poppins

Body Font: Open Sans

Wireframes

The website will use responsive layouts for desktop, tablest, and mobile screens. The wireframes will show the planned structure and arrangement of content for each page.

Desktop View

A wide layout with the site header and navigation ath the top, followed by the main content arranged across the available screen width.

Tablet View

A medium-width layout with a responsive header and navigation, with content arranged to fit comfortably on a tablet sreen.

Mobile View

A single-column layout with a responsive navigation menu and content stacked vertically for easy viewing on smaller screens.

Planned Technologies

  • HTML
  • CSS
  • Javascript
  • JSON
  • Remote API

Dynamic Features

Javascript will be used to display Dynamic football information, while JSON and a remote APPI will provide data such as fixtures, results, and player information.

Accessibility

The website will use semantic HTML, descriptive image alt text, readable Typography, sufficient color contrast, keybaord friendly navigation, and responsive layouts.
